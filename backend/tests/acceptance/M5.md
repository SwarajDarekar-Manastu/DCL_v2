# M5 acceptance: Route A1 crops and the vision sub-pipeline (crop part)

Source: `docs/architecture/10_development_plan.md` §5 M5, plus the Lead's crop rules of 2026-10-23 after the
user's inspection of stored crops (figure crops bleeding into text columns, handwriting slivers, no table
crops). Read-only: the database in a read-only transaction, MinIO only asked whether an object exists.

```bash
DCL_ACCEPTANCE=1 DCL_DATABASE_URL=<stack db> DCL_MINIO_ENDPOINT=<url> DCL_MINIO_ACCESS_KEY=<key> \
  DCL_MINIO_SECRET_KEY=<secret> uv run pytest backend/tests/acceptance/test_m5_acceptance.py -v
# counts and the first ten violations per check:
DCL_DATABASE_URL=... DCL_MINIO_ENDPOINT=... DCL_MINIO_ACCESS_KEY=... DCL_MINIO_SECRET_KEY=... \
  uv run python backend/tests/acceptance/m5_state.py report
```

Each check is proven to pass on a good and fail on a bad seeded state in `test_m5_checks_on_seeded_db.py`.

| # | Rule | Check | Pass when |
|---|------|-------|-----------|
| 1 | Crops are not slivers | `test_crops_have_a_sane_size_and_page_share` | every `figure_crop` and `handwriting_crop` asset has width and height ≥ 48 px and its bbox covers ≥ 0.3 % of the page |
| 2 | Crops do not swallow the page | same test | no such crop covers > 90 % of the page unless a node using it has `metadata.class = full_page_image` |
| 3 | Tables are cropped | `test_every_a1_table_node_has_a_table_crop` | every `table` node of an A1 document points to a `table_crop` asset |
| 4 | Figures are read | `test_every_a1_figure_node_has_content` | every `figure` node of an A1 document has non-empty content |
| 5 | Contact sheet for review | `test_every_a1_document_has_a_contact_sheet` | `s3://dcl-assets/qa/{primary blob sha256}/crops.png` exists for every A1 document |

The remaining M5 criteria (page types ≥ 95 %, handwritten values ≥ 90 %, non-English OCR engine and grade,
table spans, citations to page and bbox, cost per page) need the SME-selected 30-document set and are not
automated yet.
