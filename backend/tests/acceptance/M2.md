# M2 acceptance: dispatcher and the ground-truth routes A2, B, C

Source: `docs/architecture/10_development_plan.md` §5 M2 "Accept". The Route C checks and the TP7
footer CONFLICT are executable; A2 and B rows wait for those routes. Run from the main checkout
against the stack, read-only (the database session is a read-only transaction; MinIO is only read):

```bash
DCL_ACCEPTANCE=1 DCL_DATABASE_URL=<stack db> DCL_MINIO_ENDPOINT=<url> DCL_MINIO_ACCESS_KEY=<key> \
  DCL_MINIO_SECRET_KEY=<secret> uv run pytest backend/tests/acceptance/test_m2_acceptance.py -v
```

Without the `DCL_MINIO_*` names only the Parquet check is skipped. Every check is proven to pass on a
good and fail on a bad seeded state in `test_m2_checks_on_seeded_db.py` (`DCL_TEST_DATABASE_URL`).

## TP7 footer CONFLICT (file 03 §1.2, decided 2026-10-22)

`test_tp7_footer_raises_a_test_plan_conflict`: an A1 document whose folder context says `TP07`
carries a CONFLICT SOFT on page 1 with `subject = test_plan_id`, side a `TP07` from `folder[n]` or
`filename`, side b `TP06` labelled `page 1 header or footer` whose provenance holds the printed line
"Test Campaign 2 - Test Plan 6"; the document keeps `test_plan_id = TP07`. The furniture line is
read from the flag's evidence, the one place the route persists it. Needs Route A1 in the
dispatcher and the sheet processed; until then it fails with "has the TP7 sheet gone through Route A1?".
